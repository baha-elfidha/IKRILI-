Méthode

Les chiffres utilisent la médiane, moins sensible aux annonces extrêmes que la moyenne. Un groupe n'est affiché qu'à partir de {{ min_group }} annonces. L'estimation du juste prix compare chaque logement à ses voisins les plus proches (distance, surface, pièces, type, meublé, équipements){% if quality.ridge %}, combinée à un modèle de régression entraîné sur toutes les annonces{% endif %}. {% if quality.mdape is not none %}Testée sur {{ quality.n }} annonces, l'erreur médiane de l'estimation est de {{ quality.mdape }} %.{% endif %}

Ce sont des loyers demandés dans les annonces, pas des loyers signés. Indication, pas expertise.
